# 特徵工程設計文檔

## 概述

將遊戲狀態轉換為 **98 維**特徵向量，供 Agent 決策使用。

| 區塊 | 維度範圍 | 維度數 | 說明 |
|------|---------|--------|------|
| 自身狀態 | [0-10] | 11 | 血量、CD、牆壁距離 |
| 敵人狀態 | [11-66] | 56 | 4個敵人 × 14維 |
| 血包狀態 | [67-81] | 15 | 3個血包 × 5維 |
| 投射物狀態 | [82-96] | 15 | 3個投射物 × 5維 |
| Bias | [97] | 1 | 常數 1.0 |
| **總計** | | **98** | |

---

## 程式碼架構

```
ai/
├── features.py              # FeatureExtractor 主類
├── feature_components/
│   ├── __init__.py
│   ├── self_features.py     # 自身狀態特徵
│   ├── enemy_features.py    # 敵人狀態特徵
│   ├── item_features.py     # 血包狀態特徵
│   └── projectile_features.py  # 投射物狀態特徵
```

`FeatureExtractor` 維護上一幀快照用於計算時間差分，每個 episode 開始時需呼叫 `reset()` 清除。

## 詳細特徵定義

### 自身狀態（11維）

| 索引 | 特徵 | 說明 |
|------|------|------|
| [0] | 自身血量 | current / maximum |
| [1] | 共同技能 CD | remaining / max_shared_cd |
| [2] | 技能1 CD（外圈刮） | remaining / MAX_INDIVIDUAL_CD |
| [3] | 技能2 CD（飛彈） | " |
| [4] | 技能3 CD（鐵錘） | " |
| [5] | 技能4 CD（閃現） | " |
| [6] | 技能5 CD（靈魂爪） | " |
| [7] | 技能6 CD（靈魂掌） | " |
| [8] | 技能7 CD（血池） | " |
| [9] | 技能8 CD（召喚血包） | " |
| [10] | 面前牆壁距離 | 射線投射 / world_size |

---

### 敵人狀態（14維 × 4 = 56維）

按距離排序（最近優先），死亡敵人的槽位填 0。

| 相對索引 | 特徵 | 說明 |
|---------|------|------|
| [0] | 敵人血量 | current / maximum |
| [1] | 距離 | / max_distance |
| [2] | 角度 | 相對 Agent 朝向，[-π, π] |
| [3] | 敵人朝向差 | enemy_angle - agent_angle，[-π, π] |
| [4] | 眼前1格距離 | 敵人位置 + 朝向1格 → 距離 |
| [5] | 眼前1格角度 | 眼前1格相對角度 |
| [6] | Δ距離 | 本幀 - 上幀 |
| [7] | Δ角度 | 本幀 - 上幀（歸一化） |
| [8] | Δ朝向差 | 本幀 - 上幀（歸一化） |
| [9] | Δ眼前距離 | 本幀 - 上幀 |
| [10] | Δ眼前角度 | 本幀 - 上幀（歸一化） |
| [11] | 類型：劍 | one-hot |
| [12] | 類型：弓 | one-hot |
| [13] | 類型：法杖 | one-hot |

---

### 血包狀態（5維 × 3 = 15維）

按距離排序（最近優先），不存在時填 0。

| 相對索引 | 特徵 | 說明 |
|---------|------|------|
| [0] | 距離 | / max_distance |
| [1] | 角度 | 相對 Agent 朝向，[-π, π] |
| [2] | Δ距離 | 本幀 - 上幀 |
| [3] | Δ角度 | 本幀 - 上幀（歸一化） |
| [4] | 是否存在 | 0 或 1 |

---

### 投射物狀態（5維 × 3 = 15維）

只追蹤**敵方**投射物，按距離排序（最近優先），不存在時填 0。

| 相對索引 | 特徵 | 說明 |
|---------|------|------|
| [0] | 距離 | / max_distance |
| [1] | 角度 | 相對 Agent 朝向，[-π, π] |
| [2] | Δ距離 | 負值 = 正在接近（危險） |
| [3] | Δ角度 | 本幀 - 上幀（歸一化） |
| [4] | 是否存在 | 0 或 1 |

---

## 特徵歸一化摘要

| 特徵類型 | 歸一化方式 | 範圍 |
|---------|-----------|------|
| 血量 | current / maximum | [0, 1] |
| CD | remaining / max_cd | [0, 1]，0=ready |
| 距離 | distance / max_distance | [0, 1] |
| 角度 | 原始弧度，歸一化到 [-π, π] | [-π, π] |
| Δ距離 | 原始差值 | 約 [-0.1, 0.1] |
| Δ角度 | 歸一化到 [-π, π] | [-π, π] |
| 存在標記 | 0 或 1 | {0, 1} |
| one-hot | 0 或 1 | {0, 1} |

---

## 時間差分的意義

| 特徵 | Δ > 0 | Δ < 0 |
|------|-------|-------|
| Δ距離 | 目標遠離 | 目標接近 |
| Δ角度 | 目標往右移 | 目標往左移 |
| Δ朝向差 | 敵人轉向其他方向 | 敵人轉向 Agent |
| Δ投射物距離 | 投射物遠離 | **投射物接近（危險！）** |

## 注意事項

1. **每個 episode 開始時必須呼叫 `extractor.reset()`**，清除上一幀數據
2. **時間差分在第一幀為 0**，因為沒有上一幀數據
3. **敵人按距離排序**，同一個敵人在不同幀可能出現在不同槽位
4. **投射物壽命短**，可能在幾幀內消失，需正確處理空位
