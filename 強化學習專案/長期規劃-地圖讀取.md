# 地圖讀取系統

## 使用方式

```bash
python main.py --level levels/01.json
```

不指定 `--level` 時使用硬編碼預設關卡。

---

## JSON 格式

```json
{
  "id": "my_level",
  "name": "關卡名稱",
  "room": { "size": 10.0 },
  "player": { "x": 8.0, "y": 5.0, "angle": 3.14159 },
  "monsters": [
    {
      "x": 3.0, "y": 5.0, "health": 100.0,
      "behavior": {
        "type": "berserker",
        "attack_damage": 12.0,
        "attack_range": 2.5,
        "attack_cooldown_ticks": 20
      }
    }
  ],
  "blood_packs": [
    { "x": 5.0, "y": 8.0, "heal_amount": 30.0 }
  ]
}
```

---

## 行為類型與參數

所有行為共用基底參數：`walk_speed`, `sprint_speed`, `turn_speed`, `attack_cooldown_ticks`, `attack_range`, `attack_damage`

| type | 額外參數 |
|------|---------|
| `stationary` | （無） |
| `berserker` | `sprint_threshold` |
| `hit_and_run` | `flee_distance`, `safe_distance`, `flee_duration` |
| `orbit_melee` | `target_radius`, `radius_tolerance`, `clockwise` |
| `orbit_ranged` | `weapon_type`("bow"/"staff"), `target_radius`, `danger_radius`, `clockwise` |
| `opportunist` | `attack_window_ticks` |
| `adaptive` | （無） |
| `backstab` | `backstab_angle_threshold` |
| `blood_pack_disruptor_melee` | `target_radius`, `clockwise` |
| `blood_pack_disruptor_ranged` | `weapon_type`, `target_radius`, `clockwise` |
