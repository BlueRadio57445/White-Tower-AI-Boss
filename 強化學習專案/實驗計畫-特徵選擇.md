# 特徵選擇實驗計畫

## 方法

Forward Stepwise Selection：每輪從候選特徵中選一個加入，選能讓 `avg_reward` 最大的那個，直到沒有任何候選能再提升為止。

## 訓練設置

| 參數 | 值 |
|------|----|
| Epochs | 3000 |
| Seeds | 3 個（取平均） |
| 其他超參 | 固定不變 |

## 候選特徵

（待填入）

## 每輪流程

```
1. 將每個候選特徵分別加入當前特徵集，各自訓練
2. 選 avg_reward 最高者加入特徵集
3. 若最高者仍低於當前結果，停止
4. 否則移除已選中的特徵從候選清單，進入下一輪
```

## 記錄格式

```
輪次        : [第N輪]
加入特徵    : [特徵名稱]
avg_reward  : 前=X → 後=X
決策        : 保留 / 停止
```
